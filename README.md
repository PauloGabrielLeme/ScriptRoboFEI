# Script de Instalação de Dependências para o projeto Robô FEI

Este pequeno script feito em bash tem o objetivo de automatizar a instalção das dependências
necessárias para programação no projeto Robô FEI

### Programas instalados com este script:
- Python
- ROS 2 Jazzy Jalisco
- VScode

### O script pode ser executado nas seguintes distribuições Linux:
- Ubuntu
- Debian (Stable)
- PopOS
- PikaOS
- E outros derivados do Ubuntu e do Debian.

### Instruções

##### Tenha Certeza Que o Git Está Instalado
```ps1
sudo apt install git
```

##### Clone O Repositório
```ps1
git clone https://github.com/PauloGabrielLeme/ScriptRoboFEI/
```

##### Entre No Repositório
```ps1
cd ScriptRoboFEI
```

##### Torne o Script Executável
```ps1
chmod +x robofei.bash
```

##### Execute o Script como Root
```ps1
sudo ./robofei.bash
```
